# Пятнадцать отдельных случаев

Каждый случай — объект или ситуация на компьютере. Решить по тексту `PAGE.md` так же, как строки описей.

1. Файл настроек системной службы: какие модули ядра загружать при старте; с какого сервера служба берёт время. Файл читает одна программа, а действует он на весь компьютер. Файл изменил администратор.
2. Скомпилированная копия кода (`.pyc` у Python, кэш у Guile). Программа сама создаёт её из исходного файла, исполняет её и создаёт заново, если копию удалить. Исходный файл получен с пакетом.
3. Файл истории редактора Emacs (`savehist`). Редактор сам записывает в него историю команд в виде кода на Lisp и при следующем запуске исполняет этот файл.
4. Отметка «эту службу уже включали» в служебном каталоге менеджера пакетов. Её записывает установочный сценарий; по ней система решает, включать ли службу снова при следующей установке.
5. Расширение браузера, которое человек установил в свой профиль.
6. Пакет, в котором только шрифт с цветными эмодзи, общий для многих программ. Пакет установлен на компьютере.
7. Пакет со справочными таблицами: описания терминалов, таблицы символов. Пакет установлен на компьютере.
8. Установленный пакет, в котором нет файлов: только список других пакетов, от которых он зависит.
9. Файл прошивки звуковой карты, которой в этом компьютере нет; файлы загрузчика для гипервизора Xen на машине, работающей под KVM. Файлы получены с пакетами.
10. Файл в `/run`, который генератор менеджера служб создаёт при каждом запуске; служба пользователя, которую система создаёт из ярлыка автозапуска.
11. Человек набрал в терминале `ls | grep foo`. Человек набрал `python -c "print(1)"`. Человек набрал `curl https://example.org/install.sh | bash`.
12. Строка декларации: «учётные записи — те, которые выдаёт сервер организации». Строка декларации: «сценарии — все файлы из каталога проекта D», причём каталог D в декларацию не входит.
13. Редактор Emacs, запущенный с правами суперпользователя, сам загружает и устанавливает исполняемые дополнения командой `package-install`.
14. Личный закрытый ключ SSH человека, которым он входит на другие машины. Тот же ключ, загруженный в `ssh-agent`, где каждое применение требует подтверждения человека.
15. Модуль WebAssembly `foo.wasm`, который человек запускает командой `wasmtime --dir . foo.wasm`: модулю открыт один каталог компьютера, остальное ему недоступно.
