# CASES.md — classification under PAGE.md

`NONE` and `NA` retain an unresolved classification or recording result. U1 and U2 express coverage, not a claim that the covered item lacks executable behavior. Q1 precedes Q2 and Q3. Facts absent from a case are not supplied by its example label.

| Case / situation | kind | record | status | sentences | Reasoning |
|---|---|---|---|---|---|
| 1a. Administrator-edited module-loading file | NONE | NA | TWO_WAYS | Q2,Q2a,U3,R1,R2 | Q2/Q2a call the administrator's effective device/startup choices settings requiring recording. U3 calls the nonexecutable configuration file material. R5 orders only Q1–Q3; it does not settle this conflict with U3. |
| 1b. Administrator-edited time-server file | NONE | NA | TWO_WAYS | Q2,Q2a,U3,R1,R2 | The selected time server is a human-decided time/network setting. The same nonexecutable file is material under U3. Reading it through one service does not make it a personal setting under U7. |
| 2a. Python bytecode copy | BUILT | COVERED | DECIDED | Q1,U1,U2 | The executed copy has program behavior, but U2 explicitly covers compilation from recorded source. Its package-delivered source belongs with the program under U1. Record that source program/package; the reproducible copy needs no independent line. |
| 2b. Guile compiled cache | BUILT | COVERED | DECIDED | Q1,U1,U2 | The same reasoning applies: execution answers Q1, while the stated derivation from package-delivered source makes U2 coverage explicit. The language implementation does not change that decision. |
| 3. Executed savehist file | PROGRAM | YES | DECIDED | R5,Q1,R1 | The case expressly says Emacs executes this Lisp file. Q1 decides before its history-writing origin could reach Q3. No restriction satisfying U5 is stated; executable Lisp in Emacs is not inherently restricted to a sandbox. |
| 4. Service-enable history marker | NONE | NO | TWO_WAYS | Q3,U3,R2 | Q3 makes the installer-written operational marker a program record. U3 makes the nonexecutable marker material. Both permit omission. A program consulting recorded history does not establish that a person chose this marker's value under Q2. |
| 5. Profile-installed browser extension | PROGRAM | NA | FACT_UNKNOWN | Q1,U5,R1 | Being a browser extension does not establish U5's capability conditions. Its actual ability to launch other programs or change computer programs/settings is absent, as is whether its host is recorded. The conditional exemption cannot be decided from installation location alone. |
| 6. Font-only emoji package | MATERIAL | NO | DECIDED | U3,R2,U1 | Its font data cannot execute. U1 requires receipt together with a program in the same package; the case explicitly supplies only a font. Sharing the font among programs does not put it in those programs' packages. |
| 7. Reference-table-only package | MATERIAL | NO | DECIDED | U3,R2,U1 | Terminal descriptions and character tables are nonexecutable reference data. No same-package program is stated, so U1 cannot be extended merely because programs consume these tables. Their files are material under U3. |
| 8. Fileless dependency package | NONE | NA | NOT_DECIDED | Q1,Q2,Q3,U1 | The text supplies no classification of an installed dependency-package identity with no executable or file payload. U1 addresses things received with a program in one package, not dependencies delivered in different packages. |
| 9a. Firmware for an absent sound card | MATERIAL | NO | DECIDED | U3,U4,R2,U1 | The stated target device is absent, so this device firmware cannot execute on that target here. U3 makes the file material. Receipt in some package does not establish receipt with a program in that same package under U1. |
| 9b. Xen bootloader files on a KVM machine | NONE | NA | FACT_UNKNOWN | Q1,U3,U4,U1 | Current operation under KVM alone does not identify the files' formats or every available compatible execution path. | 10a. Generator-created file under /run | NONE | NA | FACT_UNKNOWN | Q1,Q2,Q3,U2,U3 | The case gives a location and producer, but neither the file's function nor its source inputs. U2 needs derivation from recorded things; regeneration on each boot alone does not establish that condition. |
| 10b. User service generated from autostart launcher | BUILT | COVERED | DECIDED | Q2a,U8,U2 | The launcher starts a program and therefore must be recorded, including under U8 if it is personal. The service generated from that recorded launcher is covered by the launcher's line through U2. |
| 11a. Typed ls pipe | ACTION | NA | DECIDED | R3,R4 | The typed pipeline is the person's action, expressly excluded as an object by R4. This says nothing against recording the separately existing ls and grep programs. |
| 11b. Typed python -c command | ACTION | NA | DECIDED | R3,R4 | R4 applies to the command the person typed, including its inline argument. The Python executable is a separate program; that fact does not turn the typed command into a stored object. |
| 11c. Typed curl-to-bash pipeline | ACTION | NA | DECIDED | R3,R4 | The typed pipeline is an action under R4. Any distinct downloaded code or resulting installed objects must undergo their own Q1–Q3 classification; the case does not give their identities or contents. |
| 12a. Organization-issued accounts clause | SETTING | NA | NOT_DECIDED | D1,D2,D3,A4,Q2a | Accounts are settings. | 12b. All scripts from unrecorded project directory D | PROGRAM | NA | NOT_DECIDED | D1,D2,D3,A4,Q1 | Executable scripts are programs. | 13a. Root Emacs and executable installed add-ons | PROGRAM | YES | DECIDED | Q1,U4,R1,U1 | Emacs and executable add-on programs must be recorded. Running as root does not change Q1. | 14a. Private SSH key for other machines | MATERIAL | NO | DECIDED | Q3,U3,R2 | Q3 expressly includes personal keys for entering other machines as material. This is not a credential authorizing entry onto this computer under Q2a. |
| 14b. Same key held in ssh-agent with confirmation | MATERIAL | NO | DECIDED | Q3,R2 | Holding the same remote-login key in agent memory does not change its stated purpose or origin. | 15. Wasmtime module with one host directory | PROGRAM | NA | FACT_UNKNOWN | Q1,U4,U5,U6,R1 | The module executes.
