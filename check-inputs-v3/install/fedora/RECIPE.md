# Fedora Workstation installation recipe

`ks.cfg` uses `liveimg` to install the payload from the verified Fedora Workstation 45-1.4 live ISO. This retains the Workstation software selection without a `%packages` addition. The official method is described at https://fedoraproject.org/wiki/Anaconda/Kickstart/KickstartingFedoraLiveInstallation . The installer runs from the same release's Everything netboot kernel and initramfs, served at https://dl.fedoraproject.org/pub/fedora/linux/releases/45/Everything/x86_64/os/images/pxeboot/ . The initramfs downloads the same release's stage2 from that installation tree.

`install.sh` extracts only the installation payload from media, allocates an empty 40 GiB disk, takes a VM slot, and starts an unattended 4096 MiB / two-vCPU installation. Start this script through a persistent user service, with the laboratory root as working directory. Serve `C1/` at loopback port 18081 using `python3 -m http.server 18081 --bind 127.0.0.1`; QEMU's user network exposes that server as 10.0.2.2. Copy `ks.cfg` to `C1/fedora/ks.cfg` before launching.

User `user` has wheel rights and dummy password `cal-test`; root password is locked. English and UTC make records consistent. Serial console boot arguments enable command transport without extra packages. These are instrumentation choices. First-boot questioning is disabled because the installation has already supplied its account. Partitioning remains automatic; the verified Workstation image supplies the desktop selection. Only install, boot, login and constant-output smoke are permitted on the clean system.

The boot argument `inst.profile=fedora-workstation` explicitly selects Workstation installer defaults even though netboot starts from the Everything tree. Source: https://anaconda-installer.readthedocs.io/en/latest/developer/configuration-files.html and https://anaconda-installer.readthedocs.io/en/latest/user-guide/boot-options.html . A first draft attempt omitted this option and was stopped before smoke; it is not the backing installation.
