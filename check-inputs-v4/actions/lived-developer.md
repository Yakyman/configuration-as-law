# Developer workstation actions

Base: a disposable copy of the previous night's clean Fedora Workstation installation. These are fixed inputs for the investigation beyond the plan in PROTOCOL.md Section 5. No machine was started or changed while preparing this file. The script has 13 actions; `bash -n` passed. Runtime success remains for C1-REH to determine.

Run `bash lived-developer.sh` as the guest's ordinary `user`, with `lib.sh` beside it, working Internet access, administrator authorization through the library's `root` helper, and an existing systemd user session/bus. Administrative commands use that helper; downloaded language installers and Homebrew run as the ordinary user. The library dispatches each function with the timeout below and writes its name, exit status and elapsed duration to `~/actions-status.tsv`. A zero status describes completion of the commands, not a completed inventory or acceptance of the investigation.

The exact unit files, Dockerfile, hook configuration, SSH configuration and user script are embedded verbatim in `lived-developer.sh`. Project dependencies are installed under `~/Projects/scc/.cal-modcache` with the documented [GOMODCACHE override](https://go.dev/ref/mod#module-cache), shared by the download and build commands. Fedora prerequisites select `/usr/bin/curl` through DNF's [file provides](https://dnf5.readthedocs.io/en/latest/misc/specs.7.html), allowing its existing curl-minimal provider. The user's source tree, tool caches, package metadata, shell changes and running container deliberately remain for the later inventory. No public repository is written to, and no account, payment, existing key or personal data is required. The SSH key is newly generated guest material and must not be included in published raw evidence.

Choices differ from the previous build where alternatives exist: Julia/Bun instead of Rust/Node home installers; Juliaup instead of nvm; RubyGems/Bun/uv tools instead of pipx/npm/cargo tools; Micro instead of Neovim/Emacs/Visual Studio Code; scc instead of Flask/Express/zlib; Lefthook instead of pre-commit; Docker instead of Podman; Homebrew as an additional system package manager. Fedora's own Go compiler is only a build prerequisite. Standard Git, OpenSSH and systemd remain because they directly implement the required actions.

The language installer defaults intentionally modify startup files. No suppression option is set. Versions, hashes, downloaded plugin contents, package versions and actual generated startup differences are runtime evidence for C1-REH, not invented here. Network outages, unavailable packages, upstream installer changes or a missing user bus remain visible action failures. Rehearsal substitutions require a disclosed reason and an amended action list.
