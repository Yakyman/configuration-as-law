1. **Resolved and independently verified — native ownership cannot transfer an install reason to a distinct language package.** `S8.1-6` says exactly: “**Package**—what an installer installs and removes as a whole; in a system that is installed and updated as an image, the image is a package.” `S8.2-7` separately asks: “Is the object a package installed on the computer, or was it obtained as part of such a package and does it remain as received?” `S8.2-16` permits “the line of the package as part of which it was obtained.” Together with `TEXT.md:155-156`, which requires the explicit/dependency fact “for each package,” exact native ownership of `METADATA` or `package.json` proves provenance under the native parent; it does not prove why the distinct Python or npm object was installed. This is the same category error as deriving an individual RPM package reason from selected-group membership. The fixed authorization permits native manual marks, selected-set expansion, and top-level manager records, but none transfers a parent package's reason to a separately counted package object.

   The reviewed source previously transferred the native reason in the Python, npm-lock, unmatched-npm, and legacy-egg paths. The correction now in `collector/packages.py:403-529` retains `native_package_ids`, assigns Python explicit only from `REQUESTED`, uses npm's own top-level/transitive lock evidence, and leaves unmatched npm and native-owned legacy Python metadata unknown. `collector/PACKAGES.md:49` and `COLLECT.md:210-214` now state this rule consistently.

   Historical aggregate counts cannot distinguish valid own-manager language reasons from the invalid native transfer. Without opening old inventories, a proved conservative known-reason lower bound is:

   `packages:reason-known - reason:python:explicit - reason:python:dependency - reason:npm:explicit - reason:npm:dependency`

   This treats every historically known Python/npm reason as unknown. An old run can still prove the threshold only if that lower bound divided by `packages:total` is greater than 0.90. The new in-memory counters in `collector/main.py:127-142` distinguish nonlanguage known reasons, language reasons established by the language manager, native-derived language reasons, and native-linked language objects. `rehearsal/fx-finalize.py:33-40` applies the conservative subtraction to records that predate those separating counters.
