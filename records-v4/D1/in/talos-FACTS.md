### talos

All collector output is under `D1/in/raw/talos/`. `objects.tsv` columns are `id`, `machine`, `level`, `kind`, `name`, `members`, `evidence`. Strip the leading `talos-` from a `D1/in/part-talos.tsv` id to obtain the original collector id; the original machine, name, members and evidence fields are unchanged. Evidence paths are relative to `D1/in/raw/talos/`.

- Package installation reason: `D1/in/raw/talos/objects.tsv`, row kind `package`, JSON `members.reason` (`explicit`, `dependency` or `unknown`). Its `reason_evidence` points to `D1/in/raw/talos/raw/0001-talos-install-image.out`; the observed installed-image package has `explicit`. `members.integrity` is `unknown`. This is one package-like image, not a complete conventional package manifest.
- Packaged-file integrity: `D1/in/raw/talos/package-files.tsv` columns `package`, `path`, `integrity`, `evidence`, `rule`. Join `package` to the original object id. All 287 captured file/symlink candidates have `integrity=unknown`; no unchanged-file assertion is inferred from read-only backing. This is the bounded observed `/usr` namespace, not a complete image manifest.
- Complete immediate group membership: each group row's JSON `members.file` names its exact (not published: record outside selected evidence); `members.count` is its member count and `members.detail` records `complete_immediate_listing=true;ownership=unknown`. Columns: `path`, `type`, `mode`, `owner`, `size`, `mtime`, `executable`, `signature`, `persistence`. These are complete observed immediate listings only; deeper inventory remains bounded. Opaque-directory rows explicitly leave contents unexpanded.
- Stored-file persistence: the member table's `persistence` column is `unknown` for all captured members. Match an individual code/opaque object `name` to member `path` where present; the collector does not establish persistent-filesystem status for any Talos stored object.
