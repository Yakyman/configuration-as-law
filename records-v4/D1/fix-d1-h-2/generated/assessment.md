## Limits

FACT_UNKNOWN here is about membership of this particular gap, not a newly invented textual gap or a proof that the earlier RECORD decision was right. For font caches the missing fact is which fonts the cache lists and whether they came from installed packages; for the inactive database and solver cache it is the relevant source package set. No new observation was made. The original card's label concerns lists generated from installed packages; extending it to arbitrary application caches without establishing the source would silently widen its factual premise.
