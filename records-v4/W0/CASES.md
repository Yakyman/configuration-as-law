# Eight cases

Each case is an object or a situation on a computer. Some cases are to be decided under the text of version 4 (`TEXT.md`, Section 8), and where a case says so, also or only under the text of version 3 ((not published: record outside this collection), Sections 2 and 3, with the sentence numbers of `night-1122/SENTENCES.md`).

| No. | Case | Under which text |
|---|---|---|
| 1 | A font, icons and a theme obtained with a package | version 4; then version 3 |
| 2 | An installed package that contains only dependencies | version 4; then version 3 |
| 3 | A compiled copy of code that a program builds itself | version 4; then version 3 |
| 4 | A browser extension that a person installed in their own profile | version 4 |
| 5 | A game downloaded and installed by a game store | version 4 |
| 6 | The command `curl … \| bash` typed by a person | version 4 |
| 7 | A personal setting of a program, for example an editor theme | version 4 |
| 8 | An object that the system itself creates anew after removal | version 3 |
