# Ten cases

Each case is an object on a computer. Nothing here says what the object is in the terms of the definition.

1. **Shared content or capability.** A font, a translation or a theme shared by many programs.
2. **Lookup tables.** Terminal descriptions and character tables.
3. **A package containing only dependencies.** An installed package that has no files of its own and only requires other packages.
4. **Support for absent hardware.** Firmware for a device that is absent and boot files for another hypervisor.
5. **An object that the system recreates.** An object that, after it is removed, the system restores from another object.
6. **A system service setting.** A setting of a system service.
7. **A compiled copy of code.** A compiled copy of code that a program recreates itself.
8. **A history that its program executes as code.** A history file of a program that the program executes as code.
9. **A record that a service was enabled in the past.** A record that a service was enabled at some time in the past.
10. **A browser extension.** A browser extension that a person installed.
