Existing levels, columns and failure conditions stay unchanged. New module commands are the exact rehearsed structured-journal and source-separated queries, the same audit path queries, and the current-trust/use portion of the rehearsed M14 script; no additional machine probe is requested by this document.

`s4-microos-event-routes.tsv` columns: fact_id, route, query_exit, evidence, historical_chooser, scope. `all` rows apply to M03/M05/M11/M14; other rows identify a single group. Audit native exits are printed as query_exit markers inside raw output because the wrapper preserves all requested path queries. Current-trust-use output has explicit FD/MAPS delimiters and retains zero-match snapshots without claiming no prior use. Journal sender UID is not a chooser field.

The new module exposes partial sources for review, not a complete recovered fact. M14 remains not-obtainable after the three tested methods: the per-value chooser and complete actual-use records were not recovered. Future collection keeps the raw evidence; rehearsals delete it.
