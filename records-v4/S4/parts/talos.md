## Additional backing method identified before validation

The earlier mount-CLI limitation does not exclude an exact bounded kernel mount-info query. [Linux mountinfo documentation](https://man7.org/linux/man-pages/man5/proc_pid_mountinfo.5.html) states that it describes the process mount namespace, including bind roots, parent IDs and mount/superblock options. The Talos server Read implementation reads regular files in the same daemon namespace as List. Thus exact `/proc/self/mountinfo`, capped at 1 MiB and 15 seconds, is an authorized diagnostic exception to the generic pseudo traversal exclusion. It never enumerates `/proc` or reads process memory/device data. No mount query has yet been run for this new approach. Expect a complete parseable map; failure or truncation remains explicit. The third listing rehearsal already started before this method was identified; a separate fresh combined validation will tie the added query to final source. It is not a fourth changed listing approach.
