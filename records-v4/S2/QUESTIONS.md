# Questions for the author from the adjudication of supplement 1, step 2

Each item is a choice between two readings of the published text that the adjudication does not make. Rows: `S2/adjudication/rows.tsv`.

1. **A stored archive that a program unpacks and whose contained code then runs** (family 4: `void-0d4bff48fce03ced27aa83a4`, `void-a6e5bb36a961f99d2e09e83e`, and through them `void-386e90812bdecbec21d0785c`). Reading A: the archive is code that the computer executes through another program (S8.2-9), so it is a program and must be recorded. Reading B: the kernel only reads and unpacks the archive file, so by S8.2-23 it does not count as code; it was made by a program as it ran, so it is a program record (S8.2-15) and need not be recorded. Which reading does the text intend?
2. **Library source that a compiler translates into an executed program** (family 9: `developer-28b0928f32a3bd540164f5c2`, `developer-4bc7e8a9213ac909292c2e0a`, `developer-9e6d06f152c07e5c13f841e0`). Reading A: the source is code the computer can execute through another program (the toolchain) under S8.2-9, so a program. Reading B: the compiler only reads the source as input, so by S8.2-23 it is not code, and the cached copy is a program record. Which reading?
3. **A symbolic link through which a program is started under the link's name** (family 10: `server-be5afc83ca654a448cd1fb60`). Reading A: executing the link executes code, so the link is code under S8.2-9 and a program. Reading B: the link is a path value that the system only reads (S8.2-23), not chosen by a person, so a program record. Which reading?
4. **Does S8.2-21 apply to an object that question 1 has already made an installed object?** (family 5: `alma-2ea4b9f74eb9ce06f9d317ff`, `void-61a9a88ad2b852b6cf106db6`; arises only if the extension cannot launch programs or change the host, a fact unknown in the dossier). Reading A: S8.2-6 fixes the order of the questions, and the clarifications, S8.2-21 included, cannot take away the consequence of question 1, so S8.2-1 requires the add-on to be recorded. Reading B: S8.2-6 fixes only the order of the questions about what an object is; S8.2-21 is a separate rule about recording, so it applies to installed code too, and then S8.2-1 and S8.2-21 decide differently. Which reading?
5. **Files of an earlier version that the package manager has kept while a newer version of the same package is installed** (family 3: `void-2715a0cd9890aae192131492`, `void-7c442df1fb52f7545f18f9cb`; arises only once their as-received status is known). In S8.2-7, does “a package installed on the computer” mean the package by name (still installed, at a newer version) or the exact version from which the files were obtained (no longer installed)?
6. **A package archive that the installer keeps after installing it and deletes when it removes the package** (family 9: `developer-95ffe3a0117370c7c58c4a2c`; matters only if the archive has changed since receipt, a fact unknown in the dossier). Reading A: the archive is the package itself, “a package installed on the computer” (first branch of S8.2-7, no condition of remaining as received). Reading B: it is a file “obtained as part of such a package” (second branch, which requires it to remain as received). Which reading?
