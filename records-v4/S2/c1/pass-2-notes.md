# Pass 2: meaning answers

These answers were written after `pass-1.tsv` was frozen. They express the declaration requirement for the described object or role. They do not supply missing historical facts, assert that any named declaration already exists, or revise any pass-1 decision. For the documentation-defined channels, the meaning answer concerns the described artifact when present; pass 1 retains the unknown fact of actual presence.

"Own line" means the relevant installed object or chosen configuration needs explicit representation when no sufficient containing description is identified. A named covering line is a requirement on a declaration of that installation or generation operation, including the inputs and placement needed to describe its contribution. It is not a claim that a bare producer executable, without those inputs, accounts for every output it could ever write. For a group, a yes answer concerns its installed/configuration members; it does not make all accompanying material mandatory.

Every `without_forbidding` answer is `yes`. The ordinary-action list allows installation through a system/application/language package manager, extension installation, a personal-program setting change, user-service enablement, network connection, a home-directory user script, and running a container. None of the meaning requirements above requires forbidding an action on that list. An installation or setting action can first record the requested choice and then apply it; a script or generated executable can have its source/output description recorded before it becomes available for execution. Covering descriptions can include the relevant generation operation. Actions concerning material or records require no additional declaration change under these meaning answers. This is an existence judgment about the required behavior, not a claim that one of the inventoried systems already implements it, and not a claim that observation of the resulting machine is its primary description.

No gap is assigned a weight or placed in a wording/idea list. The separate answers are supplied for the independent comparison required by the task.
