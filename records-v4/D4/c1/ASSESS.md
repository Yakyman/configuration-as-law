## nixos × C1

**Demand.** S8.3-4: “**P1. Completeness.** Everything that is installed and every setting, when in force on the computer, are recorded.”
**Scope.** S8.3-1: “The properties concern the computer at any moment after a completed application of the declaration, provided there was no breaking.” S8.2-1,6–13,17 require account/rights settings to be recorded; S8.1-10–12 define their required values/existence.
**Declaration mapping (S8.1-1–3).** `/etc/nixos/configuration.nix` and its imports, as designated by the committed `check-inputs-v4/install/recipes/nixos/configuration.nix.in`; generated account databases and profiles are not designated primary text (N-D).
**Installer/package/tool mapping (S8.1-4–8).** `nix-env` is an installer; its installed package/output is a package; `nixos-rebuild` configures the system; `useradd`, `usermod` and `userdel` manage accounts and are built-in tools by their documented purposes (N-I, N-U, U-M). Shells/editors/copying/link tools are excluded except for built-in installer functionality.
**Application and success (S8.1-13–14).** completed `nixos-install` plus activation/boot, or `nixos-rebuild switch`; normal successful completion (exit 0) reports success. The supplied access recipe ends in a switch recorded as exit 0 (N-D and input provenance).
**Breaking (S8.1-15–16).** Privileged direct editing/deletion of account files outside built-in tools would be breaking and is excluded; documented account-tool operations are inside the tools and are not breaking.
**Facts and sources.** [NixOS User Management](https://nixos.org/manual/nixos/stable/#sec-user-management) says “NixOS supports both declarative and imperative styles of user management.” The release option documentation expressly permits adding users with ordinary `useradd` when `users.mutableUsers` is true (the default); it updates account databases, not the designated Nix text (N-U).
**Record boundary.** The documentation settles this fact, so no property experiment was run. The clean clone started and was destroyed; `raw/nixos-new.txt`, `raw/nixos-destroy.txt`.
**Decision: does not have.** A newly chosen account can exist without a corresponding declaration line. It is an in-force account setting (S8.1-11; S8.2-11–13,17), not a package-installation default or an external list entry. One such ordinary account creation refutes C1. No unmappable notion prevents this decision.
