2. Integration image: `build-console-02.log` and `integration/summary.json`. Backend/daemon/scheduler and declaration-path checks ran on a fresh VM. The initial driver stopped before power-cut tests; `integration/original/D07.log` completes those still-unrun add/change/remove cases on a separate fresh VM.
3. BC1 integration suite: 155 assertions, three failed. Two exposed the read-only two-file `stand-compare` shortcut around application exclusion. One library assertion used a bare SONAME: the loader returned ENOENT after failed search, which does not prove explicit authority refusal. Direct package, manager, NetworkManager, BlueZ, firewall and account denials otherwise passed; positive workflows and injected live readback failure passed.
4. Before the final rebuild: all compare paths now acquire the nonblocking transaction lock; sudo compare reads drop supplementary groups, gid and effective uid to the caller. The library assertion now uses the observed absolute library path, expecting EACCES. tmpfs sizes are fixed by the recipe (1 GiB `/tmp`, 256 MiB `/run` and `/dev/shm`) before enforcement flags. Protected package helper/library directories are also inaccessible; their exact required DAC states, caches and scheduler spools now have an explicit factory `rule` line. Additional environment assertions require isolated Python/fixed backend environment to ignore caller injection, while sudo rejects environment overrides. These changed mechanisms and more precise assertions justify the rebuilt-image rerun.
