# Ordinary-work and version evidence

Accessed UTC 2026-11-22T04:34:28.981231+00:00. Primary-source excerpts only; no hardware experiment is reported.

- O1 — https://networkmanager.pages.freedesktop.org/NetworkManager/NetworkManager/gdbus-org.freedesktop.NetworkManager.Settings.html — “The connection is persisted to disk.” AddConnection2 has separate in-memory and persistent modes. A declaration broker must mediate both, prevent automatic activation before commitment, and compare saved profiles plus required availability. The API itself does not write a declaration.
- O2 — https://bluez.readthedocs.io/en/latest/device-api/ — “initiate pairing and then retrieve all SDP records”. Pair is an operation, not evidence of persistence or a declaration transaction. Need local identity, bond/trust policy, an authentication tool, and state readback; external device availability is not guaranteed by a local profile.
- O3 — https://bluez.readthedocs.io/en/latest/adapter-api/ — “It will remove also the pairing information.” RemoveDevice supplies local bond removal. Controller power is not persistent through restart, so an explicit power requirement needs boot reapplication. No claim about erasing a remote peer's state.
- O4 — https://help.libreoffice.org/latest/en-US/text/shared/01/securitywarning.html — “Does not allow macros in the document to run.” Macro-disabled editing remains document editing. A user-selectable macro toggle is not immutable policy; unrecorded same-rights document macros require mediation, confinement, or denial. This source does not prove every office-suite execution entry point is covered.
- O5 — https://www.chromium.org/developers/design-documents/multi-process-architecture/ — “The renderers use the Blink open-source layout engine for interpreting and laying out HTML.” Renderer executables are programs distinct from webpage contents. Record browser, renderer and service binaries; page code confined to their interface has the express S2.2-11 exemption. Native helper programs remain recorded.
- O6 — https://www.gnu.org/software/emacs/manual/html_node/emacs/Package-Installation.html — “then downloads and installs it.” The documented editor contains package-install. This supplies a concrete overlap for the program-purpose and general-purpose-editor categories; it is not merely an undocumented shell escape.
- V1 — https://www.debian.org/News/2026/20261121 — “eighth update of its stable distribution Debian 13”. Current point release is Debian 13.8, dated 2026-11-21. This is distribution evidence, not a booted probe.
- V2 — https://packages.debian.org/trixie/linux-image-amd64 — “linux-image-amd64 (6.12.117-1)”. Dependency linux-image-6.12.117+deb13-amd64. Baseline stable kernel; do not assume it has later execution-check ABI.
- V3 — https://packages.debian.org/trixie-backports/linux-image-amd64 — “linux-image-amd64 (7.3.4-1~bpo13+1)”. Dependency linux-image-7.3.4+deb13-amd64. Exact available newer Debian kernel package for prospective design; this is explicitly backports, not the stable default or a measured guest.
- V4 — https://www.kernel.org/ — “7.3.5”; “2026-11-17”. Upstream stable release at access, distinct from the packaged backport. LTS 6.18.64 also listed for 2026-11-17. No heavy download or build performed.
- V5 — https://docs.kernel.org/6.14/userspace-api/check_exec.html — “All files that contain executable code, from the point of view of the interpreter, should be checked.” This versioned document proves the API is documented in 6.14. It does not prove any particular distribution interpreter implements all those checks. File-descriptor checks must cover nested code loads and libraries; interactive securebits are cooperative semantics.

Limit: the cited interfaces preserve a route to each ordinary action. Their combined transaction, authorization policy and actual adapter behavior have not been built or accepted here.

- O7 — https://docs.kernel.org/admin-guide/LSM/Yama.html — “no processes may use ptrace with PTRACE_ATTACH nor via PTRACE_TRACEME.” A documented denial option exists; complete memory-injection restriction additionally covers process_vm_writev and proc memory access by mandatory policy/seccomp. Development debugging and some crash reporters are affected.
- O8 — https://www.qemu.org/docs/master/user/main.html — “calling the equivalent host system call.” User-mode emulation executes translated programs using host operations; it is not automatically the S2.2-11 guest-system exemption. Record and admit emulated programs and their loaders, or deny that host-emulation entry.
- O9 — https://docs.kernel.org/admin-guide/binfmt-misc.html — “which interpreter has to be invoked with which binary.” Registered interpreters are additional C7 launch routes; fixed registrations can retain opened interpreter references. Registration and revocation must be mediated, including namespace-specific instances; direct emulator invocation still needs code-input checks.
- O10 — https://firefox-source-docs.mozilla.org/toolkit/components/extensions/webextensions/basics.html — “implementation of a WebExtensions API runs with full chrome privileges”; “special type of extension called a privileged extension”. A WebExtensions Experiment can package privileged API code inside the extension. Distinguish this implementation from its restricted extension-page caller. This documents the same-rights-code candidate, not a claim all ordinary extensions are privileged.
- O11 — https://chromium.googlesource.com/chromium/src/+/refs/heads/main/extensions/docs/security_faq.md — “extensions can read all files on disk”. File-access permission can expose filesystem reads; general native execution is still intended to be unavailable. This supports distinguishing extension capabilities, not universal same-rights status. The page also documents surviving injected page scripts after uninstall: code-holder restart matters.
- O12 — https://docs.wasmtime.dev/security.html — “There is no raw access to system calls or other forms of I/O”. WASI permits only granted filesystem capabilities; a module can access a selected host directory without all the runtime's rights. This supplies the concrete partial-interface variant C7.21, independent of the text's express browser-extension example.
- O13 — https://docs.wasmtime.dev/cli-options.html — “wasmtime --dir . foo.wasm”. The documented option grants a directory to the module. This is a command from documentation, not an experiment performed in this task.
- V6 — https://packages.debian.org/trixie/systemd — “systemd (257.13-1~deb13u1)”. Exact current package in stable; the 257 manuals describe the selected generation of facilities.
