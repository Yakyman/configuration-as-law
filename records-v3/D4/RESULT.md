## Separately reported indicator: Built-in tool

The complete list of recorded S3-8 allegations is **`nix-shell` on NixOS, recorded by c2**. c1 records none. **Indicator outcome: 1; the alleged counterexample is not confirmed.** This is separate from the six system/property cases.

Checked evidence: [N0](c2/raw/N0-output.txt) lists the installed `nix-shell`. [D-X2](c2/raw/docs.md), preserving the [Nix reference manual](https://nix.dev/manual/nix/stable/command-ref/nix-shell.html), documents building the specified derivation's dependencies and then starting an interactive shell with its environment; the synopsis includes the packages option. These are facts about its documented purpose, not an inference from its name.

Resolving sentence S3-6: “**Built-in tool.** A program of the system whose purpose, according to its documentation, includes changing what must be recorded: a package manager, including package managers of programming languages and of application packages; account and rights management; the service manager; network and firewall configuration.”

S2.2-9: “a program that runs on the computer must be recorded regardless of how it was installed—including an application package (Flatpak), a program in the home directory, and a program in a container;”

S2.1-3: “**In force**—for an object that must be recorded (Section 2.2): a program or code runs or can be started, a service is enabled, an account exists, a rule is applied, a saved network or a login key is available to the program that uses it, firmware or a boot order is set on the device.”

c2 erred by treating installation into a profile as a necessary unresolved boundary. The documented purpose includes building dependencies and supplying a package environment in which programs can be started; this changes what must be recorded under the quoted sentences. S3-6 does not require profile installation. Its purpose criterion therefore decides `nix-shell` as a built-in tool.

S3-7: “General-purpose programs—an editor, file copying, link creation, the command shell—are not built-in tools: changing with them, through superuser privileges, what must be recorded is breaking.” The documentation distinguishes the dependency-building program from the interactive shell it subsequently starts. Starting that shell does not make the invoking program the command shell excluded by S3-7.
